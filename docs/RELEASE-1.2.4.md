# H0sS-Money 1.2.4

- قسم **الإيرادات والمصروفات**: جدول بتاريخ العملية وبيانها وحسابها، وعمود مستقل للإيراد وآخر للمصروف، وصافي تراكمي وإجمالي الفترة. فلاتر الفترة والحساب، وتصفح 50 عملية في الصفحة مع إجماليات تشمل كامل الفترة.
- الميكروفون يستخرج العمليات المختلطة ويصنّف كل بند إلى مصروف أو إيراد أو دين لك/عليك أو سداد/تحصيل أو تحويل بين حساباتك. راجع النص والنوع والمبلغ والتاريخ والحساب قبل الحفظ. النوع الملتبس يتطلب اختيارًا ولا يُحفظ كمصروف تلقائيًا.
- حفظ التسجيل كاملًا في معاملة SQLite واحدة؛ أي مبلغ أو حساب أو سداد غير صالح يلغي القائمة كلها. السداد والتحصيل مرتبطان بالدين ويحدّثان المتبقي والحساب، دون إنشاء عملية ثانية مكررة.
- شعار بداية متجهي جديد بلا مستطيل مدمج، مع إعداد موارد أندرويد الأصلية وخلفية موحدة للوضعين الفاتح والداكن وشريطي النظام.
- جميع الميزات السابقة محفوظة: الحسابات، الديون، التكرار، الإحصائيات، PDF والصور، Google Drive، النسخ JSON والقفل والخط العربي.

الصافي المعروض = الإيرادات المسجلة − المصروفات المسجلة؛ يشمل سداد وتحصيل الدين المثبتين، ولا يشمل أصل الدين غير المسدد أو الرصيد الافتتاحي أو التحويلات الداخلية. يعرض صافي حركة العمليات، وليس تقرير أرباح محاسبيًا لنشاط تجاري. تسجيل أصل الدين للتتبع فقط؛ الاقتراض أو الإقراض المصحوب بحركة نقدية مبهمة يحتاج مراجعة.

الصوت يحتاج مفتاح مزوّد وحصة متاحة؛ Gemini للصوت والتحليل يستخدم طلبًا واحدًا. اختبارات مسارات المزودين بمحاكاة الاستجابات لا تؤكد دقة التعرف على صوت كل مستخدم أو توفر الخدمة الخارجية.

**التثبيت:** إذا كانت نسختك 1.2.2 أو أقدم، صدّر JSON خارج التطبيق قبل حذفها، ثم ثبّت النسخة ذات التوقيع الخاص واسترجع JSON. أعد إدخال مفاتيح AI. النسخة 1.2.3 ذات التوقيع الخاص نفسه تقبل التحديث المباشر.

النشر العام مشروط بنجاح TypeScript و28 اختبارًا، وفحوص Expo، وبناء النسختين، واختبارات الواجهات والتصدير على Android 10 و15 و16. لا يمثل ذلك ضمانًا بانعدام كل الأخطاء؛ الاختبار الحي لحساب Google وهاتف Xiaomi والميكروفون الحقيقي منفصل عن اختبارات المحاكيات.
