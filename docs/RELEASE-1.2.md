# H0sS-Money 1.2 — نطاق الإصدار والتحقق

## الوظائف

- العربية بخط Hoss Arabic مشتق من Noto Sans Arabic مع ترخيص OFL؛ الكلمات العربية حول الرسوم تستخدم Text أصلية.
- شعار محفظة وحرف H، وثيم كحلي/تركواز، وبداية فاتحة وداكنة.
- الإعدادات أقسام تفتح صفحات منفصلة؛ إدارة المصاريف من الرئيسية وسجل المصاريف.
- الأسبوع وآخر 30 يومًا والشهر الحالي وفترة مخصصة حتى 730 يومًا؛ كل الفئات ظاهرة.
- تاريخ وحساب عند الإضافة، وتكرار مصروف، وتراجع عن آخر حذف خلال بقاء صفحة المصاريف مفتوحة.
- دليل بداية، وحالة مفاتيح AI ونتيجة الاختبار في الجلسة.
- حالة تجهيز النسخ المحلية ورفع Drive، وتذكير أسبوعي محلي اختياري.
- حسابات برصيد افتتاحي، دخل، وتحويلات قابلة للحذف. كل الحسابات بعملة العرض نفسها؛ تغييرها لا يحوّل الأموال.
- ديون لك أو عليك وسداد جزئي؛ السداد يسجل دخلًا أو مصروفًا. أصل الدين للتتبع ولا يولد حركة نقدية.
- مصاريف أسبوعية وشهرية متكررة، إيقاف وتعديل وحذف. التسجيل يدوي أو تلقائي عند فتح التطبيق فقط، لا أثناء إغلاقه. بحد أقصى 120 استحقاقًا لكل قالب في الدورة؛ الباقي في الدورة التالية.

## البيانات

ترحيل SQLite إلى الإصدار 3؛ المصاريف القديمة تتبع النقدية الافتراضية. JSON v3 يشمل الحسابات والدخل والتحويلات والديون والسداد والقوالب. يقبل v1 وv2. الدمج بالمعرفات الدائمة مع ربط العلاقات والتحقق من تعارض السداد قبل اعتماد المعاملة. مفاتيح API ورموز OAuth لا تُصدّر.

## التحقق

- npm run check، expo-doctor، وتجهيز Hermes قبل APK.
- ترحيل قديم، دمج واستبدال النسخ القديمة والجديدة، تكرار الاستيراد، والتراجع عند الفشل.
- حفظ مصروف ودخل على Android 15 و16 وإعادة التشغيل.
- فتح الحسابات والديون والتكرار والإعدادات بدون خطأ تنقّل.
- صور الإحصائيات كاملة والوضعين وحواف النظام والبداية.
- شاشة صغيرة وخط كبير ولوحة مفاتيح وتواريخ طويلة.
- الصوت والبصمة وDrive وطلبات AI الحقيقية تحتاج جهازًا وحسابات فعلية؛ لا توصف بأنها مختبرة دون دليل.

## زمن البناء

نتائج التجميع الأصلية محفوظة حسب المعمارية والاعتماديات، مع Gradle build cache. مفتاح التخزين جديد لكل كود ويسترجع آخر نتيجة متوافقة؛ أول بناء يملأ التخزين ولا توجد مدة مضمونة. تُكتب مدة التجميع في ملخص Actions. التوثيق وأداة الاختبار لا يعيدان بناء APK على push.

## التوقيع

إصدار المراجعة بنفس شهادة Expo development المطابقة لـ v1.1.0. تحسين release لا يجعلها شهادة إنتاج. يلزم مفتاح خاص ثابت للنشر الإنتاجي؛ تغييره يمنع التحديث المباشر فوق الشهادة السابقة.
