## الميزات

| القسم | ما يمكنك فعله |
| --- | --- |
| **المصروفات** | تسجيل يدوي أو صوتي، مراجعة عدة أصناف قبل حفظها، تعديل وبحث وفلاتر وتراجع عن آخر حذف |
| **الحسابات والإيرادات** | إدارة الحسابات، تسجيل الدخل والتحويلات، ومتابعة الأرصدة |
| **الديون والتكرار** | متابعة الديون والسداد الجزئي، وإعداد مصروفات أسبوعية أو شهرية متكررة |
| **الإحصائيات والتقارير** | اختيار الفترة، توزيع الفئات ومقارنة الأشهر، وتصدير صورة أو PDF بتفاصيل العمليات والإيرادات والصافي |
| **الميزانيات** | ميزانيات للفئات وهدف شهري وتنبيهات للإنفاق |
| **المظهر والحماية** | وضع فاتح وداكن، شعار مخصص، وقفل ببصمة أو رمز الجهاز |

## ابدأ الاستخدام

1. اضبط العملة والحسابات والفئات من **الإعدادات**.
2. سجّل مصروفًا أو إيرادًا، وراجع البيانات قبل الحفظ.
3. تابع الأرقام من **الإحصائيات** وصدّر التقرير المناسب.
4. احتفظ بنسخة احتياطية دوريًا.

## التسجيل الصوتي والذكاء الاصطناعي

أدخل مفتاح المزوّد من **الإعدادات ← الذكاء الاصطناعي**، ثم اختر مزوّد الصوت والتحليل:

- **Gemini:** تحويل الصوت وتحليل المصروف؛ طلب واحد للتسجيل عند اختياره لكليهما.
- **OpenAI:** تحويل الصوت وتحليل المصروف.
- **Z.ai / GLM-5:** تحليل النص؛ تحويل الصوت يتم عبر Gemini أو OpenAI.

يمكنك ذكر عدة أصناف في التسجيل نفسه. راجع النص وكل صنف وسعره وفئته قبل الحفظ؛ قد يخطئ النموذج أو يفوّت صنفًا. الصوت يحتاج اتصالًا بالإنترنت ومفتاحًا صالحًا وحصة متاحة لدى المزوّد.

## بياناتك

البيانات المالية محفوظة محليًا، ومفاتيح API محفوظة في SecureStore ولا تدخل في النسخ الاحتياطية. التسجيلات والنصوص تُرسل إلى مزوّد AI الذي تختاره، ونسخ Google Drive تُرفع عند طلبك.
