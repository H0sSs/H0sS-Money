## أبرز ميزات التطبيق

- إصلاح رفض Gemini لطلب تحليل التسجيل بخطأ 400 مع الحفاظ على التحقق المحلي من العمليات.
- إبقاء خانات الكتابة فوق الكيبورد وداخل النماذج، بما فيها القوائم المتعددة وأزرار الحفظ الثابتة.

- إصلاح تعليمات الصوت المتسربة، والتمييز بين الأسئلة والعمليات، وحساب الكمية وسعر الوحدة مع مراجعة المبلغ المبهم.
- سجل مصاريف ببطاقات وإجماليات يومية وفلاتر الحساب والفئة والبحث والترتيب، وتصدير النتائج المعروضة فقط.
- تصحيح النص المسموع وإعادة تحليله بطلب صريح، وانتظار محدود لتصدير PDF مع استعادة محلية واحدة عند تعطل المحرك.

- تقرير شامل متعدد الصفحات للفترة والحسابات والأقسام المختارة، مع معاينة وتصدير PDF وCSV.
- ملف شخصي للاسم والبيانات والصورة، وظهور اختياري في التقرير. اسم التطبيق ثابت.
- دليل استخدام عربي قابل للبحث من الإعدادات.
- فحص اتساق البيانات والتراجع الآمن عن آخر قائمة محفوظة من الرئيسية، وتحذير العمليات المتشابهة قبل حفظها.
- اختيار النموذج لكل مزود، وجلب قائمة Gemini بالمفتاح المحفوظ. الحصة ودعم الصوت يتحددان لدى المزود.
- حذف الفئة المطلوبة مع حفظ عملياتها القديمة في «أخرى».

## كل ما تحتاجه لمتابعة أموالك

### تسجيل أسهل، ومراجعة أوضح

سجّل المصروف والإيراد والدين والسداد في تسجيل صوتي واحد. يحدد التطبيق نوع كل بند، والعملية الملتبسة تحتاج مراجعتك قبل الحفظ. راجع أسعارها وفئاتها وحساباتها وتواريخها قبل حفظ القائمة، ثم عدّل وابحث وفلتر أو تراجع عن آخر حذف.

### حساباتك وإيراداتك في مكان واحد

افتح جدول **الإيرادات والمصروفات** لعرض الإيراد والمصروف في عمودين مستقلين، مع الصافي التراكمي وإجمالي الفترة. اختر الفترة والحساب. أنشئ حسابات بأرصدة افتتاحية، وسجّل الدخل والتحويلات بينها. تابع الديون والسداد الجزئي، وجهّز المصروفات الأسبوعية والشهرية المتكررة.

### أرقام تساعدك على فهم إنفاقك

اختر أسبوعًا أو 30 يومًا أو شهرًا تقويميًا أو فترة مخصصة. راجع توزيع الفئات ومقارنة الأشهر، وحدّد ميزانيات وهدفًا شهريًا مع تنبيهات الإنفاق. صدّر صورة أو تقرير PDF للإحصائيات، أو افتح التقرير الشامل لاختيار الأقسام ومعاينة الصفحات وتصدير PDF وCSV.

### تجربة تناسبك وتحافظ على بياناتك

واجهة موحّدة بخط Tajawal العربي، مع بداية متناسقة للشعار والخلفية. اختر الوضع الفاتح أو الداكن وشعارك داخل التطبيق. فعّل قفل البصمة أو رمز الجهاز، واحتفظ بنسخة JSON أو اختر حساب Google الموجود على هاتفك لرفع نسخة يدويًا إلى Drive بعد تفعيل إعداد المشروع من مالك التطبيق.

## التسجيل الصوتي والذكاء الاصطناعي

من **الإعدادات ← الذكاء الاصطناعي**، أدخل مفتاح المزوّد واختر خدمة الصوت والتحليل.

| المزوّد | تحويل الصوت | تصنيف العمليات |
| --- | :---: | :---: |
| **Gemini** | ✓ | ✓ |
| **OpenAI** | ✓ | ✓ |
| **Z.ai · GLM-5** | عبر Gemini أو OpenAI | ✓ |

عند اختيار Gemini للصوت والتحليل معًا، يستخدم التسجيل **طلبًا واحدًا**. الصوت يحتاج الإنترنت ومفتاحًا صالحًا وحصة ووصولًا للنموذج لدى المزوّد. النموذج الافتراضي هو `gemini-2.5-flash`، ويمكن تغيير معرف النموذج وجلب قائمة Gemini من الإعدادات؛ [Google تقصر عائلة 2.5 على المستخدمين الذين استخدموها سابقًا](https://ai.google.dev/gemini-api/docs/deprecations)، ولذلك المفتاح الجديد وحده لا يضمن الوصول. راجع النص والأصناف قبل الحفظ؛ نتائج الذكاء الاصطناعي قد تحتاج تصحيحًا أو إضافة صنف مفقود.

## التحميل والتحديث

مسار البناء يختار آخر إصدار عام تلقائيًا كقاعدة، ويتحقق من بصمات APK وتوقيعها وأرقامها ومحاذاة 16 KB وتوافق المصدر قبل إعادة الاستخدام. يمكنك حذف الإصدارات والـTags الأقدم مع الاحتفاظ بآخر إصدار وTag الخاص به. إذا كان سورس التطبيق المنشور لم يتغير، يُنفذ فحص التوافق فقط. أي تغيير في التطبيق يحتاج رفع version وversionCode؛ تغييرات المكتبات الأصلية تحتاج بناءً أصليًا كاملًا.

المتطلبات: Node.js 24 وJava 17 وAndroid SDK للبناء الأصلي. يحتفظ `scripts/rebundle-apks.py` بمكتبات وموارد APK المبني عند إجراء إصلاح JavaScript فقط، ويتطلب مفتاح التوقيع الخاص وإعداد نسختي APK صراحةً؛ يتحقق من توافق المكتبات والموارد، ويحدّث بيانات رقم الإصدار أيضًا. تغيير مكتبات Native أو إعداداتها يحتاج بناءً أصليًا كاملًا بدل هذا المسار.
