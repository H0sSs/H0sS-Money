# H0sS-Money 💸

تطبيق أندرويد عربي لتتبع المصاريف اليومية بالصوت — يعمل بشكل **مستقل تماماً** بدون أي backend أو سيرفر.

كل بياناتك على هاتفك فقط (SQLite محلي)، والذكاء الاصطناعي يستخدم مفاتيحك الشخصية.

---

## ✨ المميزات الكاملة

### 🎤 إدخال صوتي ذكي
- اضغط زر الميكروفون وقل: *"اشتريت سجاير بـ 50 جنيه"*
- التطبيق يحوّل صوتك لنص ويستخرج المبلغ + الوصف + الفئة تلقائياً
- يدعم مزودَين:
  - **Gemini** (افتراضي — مجاني، 1500 طلب/يوم)
  - **OpenAI** (gpt-4o-mini)
- اختر المزود من شاشة الإدارة

### 💾 قاعدة بيانات محلية
- SQLite + Drizzle ORM
- لا يوجد سيرفر، لا تتبع، لا اشتراكات
- 11 فئة جاهزة (طعام، مواصلات، صحة، ترفيه، فواتير، تسوق، تعليم، عمل، سفر، هدايا، أخرى)

### 📊 إحصائيات وتحليلات
- **الشاشة الرئيسية**: إجمالي اليوم + ملخص آخر 7 أيام (مع نسبة التغير عن الأسبوع السابق + أكثر فئة + أعلى يوم)
- **شاشة الإحصائيات**: 
  - رسم خطي يومي قابل للنقر — اضغط أي يوم لرؤية تفاصيله
  - **التنقل بين الأيام** داخل نافذة التفاصيل (سهم → / ←)
  - رسم دائري للفئات
  - مقارنة الشهر الحالي بالسابق
  - أكبر 3 مصاريف لكل يوم
- **هدف شهري** مع حلقة تقدم بصرية

### 💰 ميزانيات وحدود
- ميزانية شهرية لكل فئة من شاشة الإدارة
- إشعارات تحذيرية عند 80% و 100% من الميزانية

### 🔔 إشعارات ذكية
- تنبيه عند تجاوز ميزانية فئة
- تنبيه يومي إذا تجاوزت متوسطك اليومي
- **سجل إشعارات كامل** في شاشة الإدارة (معاينة + نافذة كاملة)
- إمكانية مسح السجل

### 📤 تصدير ومشاركة
- **CSV**: من شاشة المصاريف (زر "تصدير")
- **PDF / صورة**: من شاشة الإحصائيات (مشاركة الإحصائيات كصورة)

### ☁️ نسخ احتياطي يدوي على Google Drive
- نسخ احتياطي كامل لقاعدة البيانات
- استرجاع من نسخ سابقة (قائمة بكل النسخ مع التاريخ)
- حذف نسخ قديمة
- **يدوي بالكامل** — لا توجد نسخ احتياطية تلقائية (حسب طلب المستخدم)

### 🔒 قفل بصمة الإصبع
- شاشة قفل عند فتح التطبيق
- يستخدم بصمة الإصبع أو رقم القفل في الجهاز
- تفعيل/إلغاء من شاشة الإدارة

### 🌗 وضع داكن / فاتح
- تبديل من شاشة الإدارة
- تصميم محسّن لكلا الوضعين

### 🔊 ملخص صوتي
- زر "اسمع" بجانب إجمالي اليوم
- يقرأ المصاريف بصوت عربي طبيعي

### 🧠 تصنيف ذكي
- التطبيق يتعلم من اختياراتك السابقة
- يقترح الفئة المناسبة تلقائياً عند الإدخال

### 🎨 شعار مخصص
- يمكنك رفع شعار خاص بك من شاشة الإدارة
- يُحفظ كـ Base64 في القاعدة المحلية

## 🛠️ بناء APK

### عبر GitHub Actions (موصى به)

1. ارفع المشروع على repository خاص بك على GitHub
2. اذهب لتبويب **Actions** — البناء يبدأ تلقائياً
3. بعد 15-25 دقيقة، حمّل الـ APK من **Releases** أو **Actions → Artifacts**

### محلياً (EAS Build)

```bash
npm install --legacy-peer-deps
npx eas build --platform android --profile preview
```

## 🔑 الحصول على مفاتيح API

### Gemini (مجاني — افتراضي)
[aistudio.google.com/apikey](https://aistudio.google.com/app/apikey) → أنشئ مفتاح → أضفه في شاشة الإدارة
- 1500 طلب يومياً مجاناً
- يعمل بالعربي ممتاز

### OpenAI (اختياري)
[platform.openai.com/api-keys](https://platform.openai.com/api-keys) → أنشئ مفتاح → أضفه في شاشة الإدارة
- يستخدم `gpt-4o-mini`
- مدفوع لكن رخيص جداً

```
│   ├── (tabs)/
│   │   ├── index.tsx       # الشاشة الرئيسية + ملخص أسبوعي

│   ├── db.ts              # SQLite + Drizzle
│   ├── schema.ts          # جداول القاعدة
│   ├── services.ts        # CRUD + إحصائيات
│   ├── ai.ts              # OpenAI + Gemini
│   ├── notifications.ts   # الإشعارات الذكية + السجل
│   └── drive.ts           # نسخ Google Drive اليدوية
└── components/            # مكونات قابلة لإعادة الاستخدام
```
