## ماذا يقدم التطبيق؟

| الصفحة | الوظائف |
| --- | --- |
| **الرئيسية** | ملخص اليوم وآخر 7 أيام، إضافة يدوية، تسجيل صوتي، وتأكيد المصروف قبل حفظه |
| **الإحصائيات** | رسوم آخر 7 أو 30 يومًا، تفاصيل الأيام والفئات، مقارنة شهرين، وتصدير PDF أو صورة |
| **المصاريف** | إضافة وتعديل وحذف، بحث وفلاتر بالتاريخ والفئة، وتصدير CSV |
| **الإدارة** | الفئات، العملة، الأهداف والميزانيات، مزودو AI، القفل، المظهر، الشعار، والنسخ الاحتياطية |

- ميزانيات وهدف إنفاق حسب **الشهر التقويمي**، وتنبيهات محلية عند 80% و100% والإنفاق المرتفع.
- قفل بالبصمة أو رمز الجهاز، وإعادة القفل بعد 15 ثانية في الخلفية عند تفعيله.
- ثيم فاتح وداكن، شعار مخصص، وملخص مسموع.
- نسخ JSON محلية أو إلى Google Drive **يدويًا**، واسترجاع بالدمج أو الاستبدال.
- تغيير العملة يغيّر وحدة العرض؛ لا يحوّل قيمة المصاريف بسعر صرف.

## ابدأ الاستخدام

1. افتح التطبيق واضبط العملة والفئات والميزانية من **الإدارة**.
2. أضف مصروفًا يدويًا من **الرئيسية**، أو جهّز مفاتيح AI لتسجيله بالصوت.
3. راجع المبلغ والوصف والفئة قبل الحفظ.
4. تابع إنفاقك من **الإحصائيات**، وابحث وعدّل من **المصاريف**.
5. اعمل نسخًا احتياطية دوريًا من **الإدارة**.

<a id="ai"></a>
## الذكاء الاصطناعي

اختيار مزوّد تحويل الصوت مستقل عن مزوّد تحليل المصروف.

| المزوّد | تحويل الصوت إلى نص | تحليل المصروف |
| --- | --- | --- |
| Gemini | نعم | نعم — Gemini 2.5 Flash |
| OpenAI | نعم — gpt-4o-mini-transcribe | نعم — gpt-4o-mini |
| Z.ai | لا في هذا التكامل | نعم — GLM-5 |

### تفعيل Z.ai / GLM-5

1. سجّل الدخول إلى [Z.ai API Keys](https://z.ai/manage-apikey/apikey-list) وأنشئ مفتاحًا.
2. تأكد من تفعيل **Model API العادي** والوصول إلى `glm-5`، وراجع [الرصيد والفوترة](https://z.ai/manage-apikey/billing). التطبيق لا يستخدم endpoint الخاص بـ Coding Plan.
3. افتح **الإدارة ← الذكاء الاصطناعي ← Z.ai**، أدخل المفتاح واحفظه واختبر الاتصال.
4. اختر Z.ai لتحليل المصروف.
5. للتسجيل الصوتي اختر Gemini أو OpenAI وأدخل مفتاحه أيضًا؛ GLM-5 يحلل النص الناتج من تحويل الصوت.

المفاتيح تُدخل داخل التطبيق وتُحفظ في SecureStore، ولا تُضمّن في الكود أو APK أو النسخ الاحتياطية.

المراجع: [دليل Z.ai](https://docs.z.ai/guides/overview/quick-start) · [GLM-5](https://docs.z.ai/guides/llm/glm-5)

## البيانات والخصوصية

- المصاريف والفئات والإعدادات محفوظة محليًا في SQLite. لا يوجد backend خاص بالتطبيق.
- الإدخال اليدوي وعرض البيانات والحسابات تعمل بدون اتصال.
- الصوت والنص يُرسلان مباشرة إلى المزوّد المختار؛ AI يحتاج الإنترنت ومفتاحًا صالحًا ورصيدًا أو حصة متاحة.
- رموز Google Drive تُحفظ في SecureStore. النسخ تُرفع فقط عند طلبك.
- استيراد نسخ v1 وv2 يتحقق من البيانات ويستخدم معاملة واحدة. الدمج يعيد ربط الفئات ويمنع تكرار المصاريف بمعرفاتها الدائمة.
- مفاتيح API ورموز OAuth وسجل الإشعارات ليست ضمن النسخ الاحتياطية.

### إعداد Google Drive على Android

1. فعّل Drive API في مشروع Google Cloud واضبط شاشة OAuth.
2. أنشئ **Web OAuth Client ID** و**Android OAuth Client** في نفس المشروع.
3. استخدم اسم الحزمة `com.hossmoney.app` وبصمة SHA-1 الخاصة بملف APK. بصمة الإصدار الحالي:

```text
5E:8F:16:06:2E:A3:CD:2C:4A:0D:54:78:76:BA:A6:F3:8C:AB:F6:25
```

4. أدخل **Web Client ID** داخل قسم النسخ والبيانات بالتطبيق.
5. أضف حسابك لمستخدمي الاختبار إذا شاشة الموافقة غير منشورة.

يلزم Google Play Services. نطاق الوصول `drive.file`، ومجلد النسخ `H0sS-Money-Backups`. الاسترجاع يحتاج الحساب الذي أنشأ النسخة. عند تغيير توقيع APK، حدّث بصمة Android OAuth.

## التطوير والبناء

**المتطلبات:** Node.js 24، npm، وJava 17 مع Android SDK للبناء الأصلي.

```sh
git clone https://github.com/H0sSs/H0sS-Money.git
cd H0sS-Money
npm ci --legacy-peer-deps
npm run check
npx expo-doctor
npm run android
```

`npm run android` يبني نسخة تطوير أصلية. Google Sign-In يستخدم مكتبة أصلية، ولذلك اختباره يحتاج development build ولا يكفي Expo Go.

| الأمر | الغرض |
| --- | --- |
| `npm start` | تشغيل Metro |
| `npm run typecheck` | فحص TypeScript |
| `npm test` | اختبارات Node وSQLite |
| `npm run check` | فحص الأنواع والاختبارات معًا |
| `npm run android` | تشغيل بناء Android محلي |
| `npm run build:android` | بناء EAS بملف preview؛ يحتاج إعداد حساب EAS |

[GitHub Actions](.github/workflows/build-apk.yml) يبني `assembleRelease` مع R8 وتقليل الموارد. ملفات البناء تظهر في **Actions → تشغيل البناء → Artifacts**، ولا تُنشر تلقائيًا كإصدار عام. تُستثنى تغييرات التوثيق وأدوات الاختبار من إعادة بناء APK على push.
